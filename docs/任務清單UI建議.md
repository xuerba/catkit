請基於目前這個桌面版「任務管理工具」界面，直接進行 UI/UX 優化。

目標：
在不改變現有核心功能和資料結構的前提下，將目前界面提升到「現代化、專業、簡潔、具有輕微科技感的桌面任務管理工具」風格。

請直接修改現有前端代碼，不要只提供設計建議。
修改完成後檢查整個頁面的視覺一致性、互動狀態和響應式效果。

========================
一、整體設計方向
========================

目前界面存在：
1. 頁面資訊層級不夠明顯
2. 表格文字和背景對比度偏低
3. 表格行高略大，導致可展示任務數量偏少
4. 搜索、篩選、狀態統計之間的層級不夠清晰
5. 底部操作按鈕不夠直觀
6. 部分按鈕只有圖標，缺少 Tooltip
7. 整體暖黃色偏多，可以保留暖色基調，但降低背景色飽和度
8. 缺少現代桌面應用常見的 Hover / Selected / Focus / Disabled 狀態
9. 任務狀態、優先級應該更加容易快速識別
10. 整體需要更有「專業任務管理工具」的感覺，而不是普通 CRUD 表格

設計關鍵詞：

Modern Desktop App
Task Management
Clean
Professional
Minimal
Soft Tech
High Information Density
Clear Hierarchy
Subtle Shadow
Rounded Corner
Smooth Interaction

不要做成花哨的 Dashboard。
不要大量使用漸變。
不要使用過度鮮豔的霓虹色。
保持簡潔、專業。
