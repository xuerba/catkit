## 1. 專案概述

一隻住在桌面上的小貓，同時是個人任務管理工具：

- **形態**：懸浮於桌面的小貓（透明、置頂、不佔工作列），會打盹、撓癢、撒嬌、翻滾、散步。
- **任務管理**：透過點擊/選單喚出任務面板，進行任務錄入、編輯、刪除、完成切換。
- **提醒**：由小貓「開口說話」——頭頂彈出對話氣泡，配合表情動作與音效。

## 2. 技術選型（已確認 PySide6）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 語言 | Python 3.12 | 現有環境 |
| UI 框架 | PySide6 | 無邊框透明視窗、QTimer 幀動畫、QPainter 自繪氣泡、系統托盤皆內建 |
| 資料庫 | SQLite（內建 `sqlite3`） | 單檔儲存 `%APPDATA%/catkit/tasks.db` |
| 音效 | `QSoundEffect`（QtMultimedia） | 播放喵聲 .wav，可靜音 |
| 打包 | PyInstaller | 單一 exe，資源檔一併打包 |

## 3. 懸浮視窗與渲染

- 視窗旗標：`FramelessWindowHint` + `WA_TranslucentBackground` + `WindowStaysOnTopHint` + `Qt.Tool`（不出現在工作列）。
- 小貓以**像素風精靈圖（sprite sheet）幀動畫**呈現：每個動作一列幀，QTimer 以 8–12 FPS 切換。
- **美術資產策略**：開發初期以程式繪製的佔位小貓（QPainter 畫簡易像素貓）先行，不阻塞開發；介面預留替換點，之後換入同等規格素材包（建議 64×64 幀、透明背景 PNG）。
- 首次啟動位置：主螢幕右下角（工作列上方）；位置以 `QSettings` 記憶。

## 4. 行為狀態機（小貓的日常）

| 動作 | 說明 | 觸發 |
|---|---|---|
| SIT 坐著 | 待機、偶爾眨眼甩尾 | 預設 |
| DOZE 打盹 | 閉眼 + 冒 Zzz 氣泡 | 待機隨機（加權） |
| SCRATCH 撓癢 | 抬後腿撓耳後 | 待機隨機 |
| CUDDLE 撒嬌 | 蹭螢幕邊/蹭游標、翻肚 | 被點擊撫摸；任務全數完成時慶祝 |
| ROLL 翻滾 | 原地打滾 | 待機隨機；完成任務時小慶祝 |
| WALK 散步 | 沿桌面水平踱步 | 待機隨機（視窗隨之移動） |
| ALERT 警覺 | 立耳、喵嗚、湊近 | 收到提醒事件 |
| FOCUS 監工 | 趴坐凝視、尾巴輕擺、頭上倒數 | （v3.0 已隨番茄鐘移除） |
| SLEEP 沉睡 | 隱藏模式/夜間自動趴睡 | （v4.3 起隱藏模式改為完全隱藏視窗；SLEEP 幀保留供空狀態圖示） |

規則：
- 無事件時每 15–40 秒隨機切換待機動作（權重可調）。
- **擬人化聯動**：未完成任務越多，打盹/散步頻率越低（貓也跟著「焦慮」）；逾期任務存在時，貓維持 ALERT 臉並定期催促。
- 拖曳中切換「被拎起」幀（四肢垂下）。

| 操作 | 反應 |

## 6. 任務提醒 = 小貓說話

- **氣泡元件**：貓頭上方圓角框 + 三角尾巴，QPainter 自繪；顯示 4–6 秒自動淡出；不搶焦點、不遮輸入。
- **氣泡大小**：支援 小／中／大 三段縮放（寬度、字體、圓角、尾巴、爪印等比縮放）；於小貓右鍵選單「氣泡大小」切換，設定存 `QSettings`。
- **提醒三段式**（文案範例）：
  1. 提前提醒（預設提前 10 分鐘）：「喵～『寫週報』再 10 分鐘就到時間囉！」
  2. 準點：「時間到啦！『寫週報』該動手了喵！」（ALERT + 拉衣角式蹭人）
  3. 逾期催促：每 10 分鐘一次，語氣漸強：「還沒開始做『寫週報』…貓替你著急喵！」
- **賴床（Snooze）**：點氣泡或面板按鈕 →「讓貓再打個盹 5/10/30 分鐘」＝ `remind_at` 順延。
- **完成慶祝**：標記完成時 ROLL/CUDDLE + 「搞定啦！喵嗚～」；全部完成時撒嬌慶祝。
- **音效**：提醒/撫摸時播放喵聲（可於托盤靜音）。

## 7. 番茄鐘（v3.0 已移除）

> **v3.0**：番茄鐘功能已整體移除（服務、資料表、UI、托盤與設置項）。以下保留歷史設計記錄。

- **啟動**：右鍵選單「開始專注」；或在任務面板對任務右鍵「專注做這項」（綁定該任務並自動切為進行中）。
- **節奏**：預設 25 分鐘工作 + 5 分鐘休息，每 4 輪長休 15 分鐘；工作時長可選 25/45/50 或自訂。
- **貓的演出**：
  - 工作中：切換 `FOCUS` 監工狀態（趴坐凝視、尾巴輕擺），頭頂常駐小型倒數氣泡（mm:ss），停用隨機動作切換以免干擾。
  - 完成：貓開心慶祝（ROLL/CUDDLE）+ 喵聲；休息輪貓同步「伸懶腰」。
  - 手動放棄：貓失落（耳朵下垂、背對數秒），記錄為 aborted。
- **閒置處理**：以 `GetLastInputInfo`（ctypes，免額外依賴）偵測系統閒置超過 3 分鐘 → 自動暫停計時，貓打盹「等你回來」，恢復輸入後續跑。
- **與任務提醒的關係**：番茄進行中，任務提醒仍照常彈出（緊急事優先於專注儀式），且不影響番茄計時。
- **資料記錄**：`pomodoros` 表記錄每次專注（見 §9），統計列末端顯示「今日番茄 N」小計；記錄資料同時為日後熱力圖/streak 擴充預留基礎。

## 8. 任務管理面板

貓頭上方彈出的半透明卡片（QFrame，可拖動、**邊緣可拖曳縮放**、點外部自動收合）：

- **標題列**：「任務清單」+ 右上角三顆視窗控制鈕（v3.2）：最小化「─」（收合，等效點外自動收合）、最大化「□」（切換佔滿可用螢幕區，還原「❐」；最大化時停用拖曳與邊緣縮放）、關閉「✕」（收起面板）。視窗支援邊緣 10px 拖曳縮放（v3.4 改自繪實作，最小 430×320）。
- **統計列（§8.1）**：面板頂部常駐四色統計標籤。
- 清單欄位：標題／分類／DRI／結束時間／優先序／狀態。
- **顏色區分**：待開始＝藍字、進行中＝橘字、已完成＝灰字劃線；逾期未完成＝整列紅字（優先於狀態色）；狀態欄以同色圓點標示。
- 操作：新增、編輯（對話框）、刪除（確認）、狀態切換（右鍵：待開始→進行中→已完成 循環）、賴床。

- 對話框欄位（v3.8 起）：標題（必填）、說明、分類／DRI／優先序（並排一行；v3.6 起分類為下拉選單：工作／生活／學習／健康／其它，預設工作）、開始時間（日曆彈出選擇器，預設當前時間）、結束時間（日曆彈出選擇器，預設「未設定」可清除，原「截止時間」更名）、提醒方式（不提醒/準時/提前 5/10/30 分鐘，同時套用於開始與結束提醒）。

### 8.1 個人任務統計（顏色標識）

統計列常駐於任務面板頂部，以彩色圓角標籤呈現各狀態數量，後接完成率細進度條：

| 分類 | 顏色 | 計數規則 |
|---|---|---|
| 待開始 | 藍 `#4A90D9` | `status = 'todo'` |
| 進行中 | 橘 `#F5A623` | `status = 'doing'` |
| 已完成 | 綠 `#4CAF50` | `status = 'done'` |
| 已延期 | 紅 `#E5484D` | `status ≠ 'done'` 且 `due_at < now`（衍生警示分類） |

規則：
- 「已延期」為警示性衍生分類，可能同時屬於待開始或進行中，獨立計數以凸顯風險；清單中該列以紅色優先顯示（蓋過原狀態色）。
- 狀態欄以同色系圓點+文字呈現；統計隨任務異動即時刷新。
- 統計標籤可點擊快速篩選（v3.5）：與搜尋列的狀態篩選下拉雙向同步；再次點擊同一標籤取消篩選（回「全部」）；作用中標籤高亮（實底色＋白字）。
- 同步應用於貓的行為與話語：撫摸速報、逾期催促開場（「已延期 1 項，貓替你著急喵！」）。
- `TaskService.stats()` 於 service 層彙總計數，UI 只消費結果。

## 9. 資料模型（基於 v1 擴充）

```sql
CREATE TABLE IF NOT EXISTS tasks (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    title       TEXT NOT NULL,
    description TEXT NOT NULL DEFAULT '',
    category    TEXT NOT NULL DEFAULT '',   -- 任務分類
    dri         TEXT NOT NULL DEFAULT '',   -- 直接負責人（DRI）
    start_at    TEXT,                   -- 開始時間（v3.1），ISO8601，可空
    due_at      TEXT,                   -- 結束時間（原截止時間），ISO8601，可空
    priority    INTEGER NOT NULL DEFAULT 1,   -- 0低 1中 2高
    status      TEXT NOT NULL DEFAULT 'todo', -- todo 待開始 / doing 進行中 / done 已完成
    remind_at   TEXT,                   -- 結束提醒時間（絕對時間）
    reminded    INTEGER NOT NULL DEFAULT 0,   -- 防重複提醒（結束）
    start_remind_at  TEXT,              -- 開始提醒時間（v3.1）
    start_reminded   INTEGER NOT NULL DEFAULT 0,  -- 防重複提醒（開始）
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL
);
```

```sql
-- v3.0 起不再建立 pomodoros 表（番茄鐘已移除；歷史庫殘留表無害，不予清理）
```

- 狀態為三態：`todo`（待開始）→ `doing`（進行中）→ `done`（已完成）；「已延期」不落庫，由 `due_at < now AND status ≠ 'done'` 即時判定。
- `ReminderService` 以 QTimer 每 30 秒輪詢 `remind_at <= now AND reminded = 0 AND status ≠ 'done'`；命中後發 Signal 給貓（說話 + ALERT 動作 + 音效），並置 `reminded=1`；賴床即回寫新的 `remind_at`。
- 逾期催促：延期的未完成任務進入催促清單，由提醒服務按節流排程發話。
- 應用程式設定（貓的位置、靜音、隱藏模式）存 `QSettings`。

### 15.2 架構

- `app/settings.py`：`AppSettings` 類別方法封裝 `QSettings`（org/app = catkit），統一 key 命名（`theme/name`、`bubble/size`、`pet/size`、`pet/opacity`、`sound/muted`、`font/family`、`font/size`、`reminder/option`；`pomodoro/*` 已隨 v3.0 移除）與型別轉換（bool/int/str）。
- `app/ui/settings_dialog.py`：`SettingsDialog`，垂直分組佈局（主題等外觀選項／提醒與音效，以分隔線隔開；v3.0 起番茄鐘組已移除，v3.3 起不再顯示「外觀」分組標籤），「儲存」寫入 `AppSettings` 後發 `settings_applied` 訊號。

## 16. 站立提醒（v4.0 已實作）

避免久坐的健康提醒，以「使用者持續活動」推估連續工作時長。

### 16.1 監控原理

- 每 10 秒以 `GetLastInputInfo`（ctypes）取得系統閒置秒數，作為「螢幕常亮且有人操作」的代理指標（無法直接讀取螢幕電源狀態）。
- 閒置 < 5 分鐘 → 視為持續工作，累積秒數；閒置 ≥ 5 分鐘 → 視為已離開（休息/鎖屏），累積歸零。
- 累積達到設定的間隔（分鐘）→ 發 `stand_due(間隔)` 訊號並歸零，進入下一輪循環。

### 16.2 介面與演出

- 任務清單標題列「🧍 站立提醒」按鈕（ghost 樣式）：點擊彈出選單——「啟用站立提醒」（勾選開關）＋間隔單選（每 30/45/60/90 分鐘），與 `AppSettings`（`stand/enabled`、`stand/interval`，預設關閉/45 分）同步。
- 觸發時小貓：氣泡「已連續工作 N 分鐘囉！站起來伸個懶腰吧，喵～」（8 秒）＋喵聲＋**固定動作 `SCRATCH`**（抬後腿伸展，one-shot 後回坐姿）；隱藏模式下靜默不打擾。
- 開關/間隔變更時貓即時以氣泡回覆確認。
