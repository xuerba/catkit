請基於目前「新增任務」頁面直接進行 UI/UX 優化。

目標：
將目前的新增任務表單改造成現代、專業、簡潔的桌面任務管理工具表單。

保持現有業務邏輯、字段、API 和資料結構不變，只優化前端 UI/UX。

==================================================
一、整體設計方向
==================================================

目前頁面的主要問題：

1. 米黃色使用過多
2. 輸入框和頁面背景區分度不足
3. 表單層級不夠清楚
4. Label 和 Input 的關係可以更明確
5. 底部「取消 / 確定」操作區不夠突出
6. 開始時間、結束時間、提醒方式缺少明確的控件感
7. 「分類 / DRI / 優先序」三個字段的視覺層級不一致
8. 整體比較像普通表單，而不是專業桌面任務工具

請保持：

Modern Desktop App
Clean
Professional
Minimal
Soft Tech

不要做成：
Dashboard
遊戲 UI
霓虹科技風
大量漸變
過度圓角
