# Catkit 打包步驟（PyInstaller + Inno Setup）

本文件記錄將 Catkit 打包為 Windows 執行檔（onedir）與安裝包（Setup）的完整步驟與指令。

> 實測環境：Windows 10、Python 3.12.10、PyInstaller 6.22.3、PySide6 6.11.2、Inno Setup 6.7.3
> 目前版本：4.5.0（產物：`dist\Catkit\Catkit.exe`、`dist\installer\Catkit-Setup-4.5.0.exe`）

---

## 1. 環境需求

| 項目 | 說明 |
|---|---|
| Python | 3.12（實測 3.12.10） |
| PySide6 | 見 [`requirements.txt`](../requirements.txt)（實測 6.11.2） |
| PyInstaller | `pip install pyinstaller`（實測 6.22.3） |
| Pillow | `pip install pillow`（`make_icon.py` 產生 ico 用） |
| Inno Setup 6 | 產生安裝包用；本機安裝於 `D:\Program Files (x86)\Inno Setup 6\ISCC.exe` |

安裝套件：

```cmd
pip install -r requirements.txt
pip install pyinstaller pillow
```

## 3. 打包步驟

所有指令皆**在專案根目錄**（`catkit\`）執行。

### 步驟 1：產生圖示（可選，圖示有變更時才需重跑）

```cmd
python packaging\make_icon.py
```

輸出：`icon written: ...\packaging\catkit.ico`

### 步驟 2：PyInstaller 建置 onedir 執行檔

```cmd
python -m PyInstaller --noconfirm --clean packaging\catkit.spec
```

- `--clean`：清除 PyInstaller 快取，確保乾淨重建。
- 建置約 40 秒；成功訊息：`Build complete! The results are available in: ...\dist`
- 產物：`dist\Catkit\Catkit.exe` 與 `dist\Catkit\_internal\`（含執行環境）。

> 驗證重點：`dist\Catkit\_internal\PySide6\Qt6Multimedia.dll` 與 `dist\Catkit\_internal\PySide6\avcodec-61.dll`
> 應存在（喵聲播放所需）。可用下列指令確認：
>
> ```cmd
> dir /b /s dist\Catkit\_internal | findstr /i "Qt6Multimedia.dll avcodec"
> ```

### 步驟 3：Inno Setup 產生安裝包

```cmd
"D:\Program Files (x86)\Inno Setup 6\ISCC.exe" packaging\catkit.iss
```

- 若 `ISCC.exe` 已加入 PATH，可直接執行 `ISCC packaging\catkit.iss`。
- 壓縮約 24 秒；成功訊息：`Successful compile`。
- 產物：`dist\installer\Catkit-Setup-4.5.0.exe`

> 安裝包行為（見 [`catkit.iss`](../packaging/catkit.iss)）：
> - 預設安裝至 `{autopf}\Catkit`（Program Files），安裝模式 `PrivilegesRequired=admin`（可於對話框切換）。
> - 開始選單捷徑；桌面捷徑（預設不勾）；開機自動啟動（預設勾選，寫入 `HKCU\...\Run`）。
> - 解除安裝**保留** `%APPDATA%\catkit` 使用者資料。

## 4. 一鍵指令（複製貼上）

cmd：

```cmd
python packaging\make_icon.py && python -m PyInstaller --noconfirm --clean packaging\catkit.spec && "D:\Program Files (x86)\Inno Setup 6\ISCC.exe" packaging\catkit.iss
```

PowerShell：

```powershell
python packaging\make_icon.py
python -m PyInstaller --noconfirm --clean packaging\catkit.spec
& "D:\Program Files (x86)\Inno Setup 6\ISCC.exe" packaging\catkit.iss
```

## 5. 產物清單

| 路徑 | 說明 |
|---|---|
| `dist\Catkit\Catkit.exe` | 主程式（onedir） |
| `dist\Catkit\_internal\` | 執行環境（Qt、DLL、翻譯檔等） |
| `dist\installer\Catkit-Setup-4.5.0.exe` | 安裝包 |
| `build\catkit\` | PyInstaller 中介檔（含 `warn-catkit.txt`、`xref-catkit.html`） |

> `dist\Catkit` 整個資料夾即為可攜執行目錄，可直接複製到其他電腦執行，不需安裝。

## 6. 版本號更新

更新版本時需同步修改以下二處（目前皆為 4.5.0）：

| 檔案 | 內容 |
|---|---|
| [`packaging/version_info.py`](../packaging/version_info.py) | `filevers` / `prodvers` / `FileVersion` / `ProductVersion` |
| [`packaging/catkit.iss`](../packaging/catkit.iss) | `#define MyAppVersion "4.5.0"` |

`catkit.iss` 的 `OutputBaseFilename` 會自動帶入版本（`Catkit-Setup-<版本>.exe`）。
版本號更新後需重新執行步驟 2 與步驟 3。

## 7. 注意事項

- **SmartScreen**：未簽署的 exe／安裝包首次執行會出現警告，選「更多資訊 → 仍要執行」。
- **Inno Setup 警告**（不影響功能）：`PrivilegesRequired=admin` 但腳本使用 HKCU（開機自啟）時，
  ISCC 會提示 `UsedUserAreasWarning`。目前採用「管理員安裝 + 開機自啟寫入 HKCU」為刻意設計；
  如需完全避免此警告，可將開機自啟改為 `HKLM\...\Run`（需管理員權限，且解除安裝需一併移除）。
- **建置前請關閉正在執行的 `Catkit.exe`**，避免檔案被占用導致 `dist\Catkit` 無法覆寫。
- **執行中的原始碼程式**（`python main.py`）不影響打包。
- `build\catkit\warn-catkit.txt` 內多為 PySide6 未使用模組的警告，屬正常現象。
- 重打包（`--clean`）會重建 `build\catkit`，並覆寫 `dist\Catkit` 與 `dist\installer` 內的舊產物。

---

## 8. 快速驗證

1. 直接執行 `dist\Catkit\Catkit.exe` 確認程式可啟動。
2. 或執行 `dist\installer\Catkit-Setup-4.5.0.exe` 完成安裝後，從開始選單啟動。
3. 功能抽查：雙擊小貓開啟任務面板 → 新增／編輯／刪除任務、狀態篩選、站立提醒（含「每 2 分鐘（測試）」）等。
